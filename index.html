  1. 01 / 03Web

    Rendra Design System

    Design system e boilerplate de sistema administrativo

    Tokens travados, três modelos, quatro paletas e mais de 50 componentes, com AppShell e telas prontas: painel, listagem, cadastro, CRM kanban, agenda e atendimento omnichannel. Para outra marca, você troca cores, fonte e ícones, e nenhum componente muda.

    • React 19
    • TypeScript
    • Tailwind CSS 4
    • Vite
    • Storybook
    npm install @rendra-ui/web
    Abrir o demo → Storybook Código no GitHub npm
  2. 02 / 03Mobile

    Rendra App

    Design system e boilerplate mobile

    O mesmo sistema de tokens do web, reconstruído para o celular: 49 componentes, navegação pronta com cabeçalho, barra inferior e menu, telas de exemplo, splash animado e troca de marca sem mexer em componente.

    • React Native
    • Expo SDK 57
    • Expo Router
    • NativeWind 4
    • TypeScript
    npm install @rendra-ui/app
    Abrir a vitrine → Código no GitHub npm
  3. 03 / 03Desktop

    Rendra IDE

    Ambiente de desenvolvimento para quem programa com IA

    Terminais em grade, o editor do VS Code, explorador com as cores do Git e um painel com o consumo de tokens do Claude Code e do Codex por projeto, com custo por token e os limites do plano. Roda na sua máquina, lendo só os arquivos locais das CLIs.

    • Electron
    • Monaco
    • xterm.js
    • Windows, macOS e Linux
    Baixar a última versão → Site da IDE Código no GitHub

O que os três têm em comum

  • Código aberto de verdade Licença MIT, código completo no GitHub, sem versão paga escondida.
  • Feitos para trabalhar com IA Cada repositório traz regras e briefing guiado para o seu agente usar o projeto do jeito certo.
  • Uma escala, sem exceção Espaço, tipografia, cor e raio vêm de tokens; o que está fora da escala não passa na checagem.
  • Publicados com procedência Pacotes npm assinados pelo GitHub Actions, com CI, testes de layout e de acessibilidade.
